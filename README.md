# StockTechnicalAnalysis
A Windows Form cppCLR application that can be uses principals of technical analysis on stock data

![Alt Text](https://github.com/AarBoone/StockTechnicalAnalysis/blob/main/2025-04-23%2023-56-05.gif)

This is a Windows Form cppCLR stock analysis tool that uses principals of technical analysis to allow the end user to predict future market behavior.
By clicking and dragging the user can define a wave that automatically caluclates the fibonacci retracement levels for that wave and calculates the beauty.
Features a button to simulate other prices to check if other prices would create a more beautiful wave.
